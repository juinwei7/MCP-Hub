接入 Hub

你的 Hub 是一台 stdio MCP server,各家 client 都是「把它當一台 MCP 加進去」。以下設定已填好你本機的實際路徑,直接複製即可。

Claude Code(CLI)

在終端機執行(local scope,只對目前專案);之後開新 session 生效。

claude mcp add my-hub -e PYTHONPATH="{{ proj }}" -- "{{ py }}" -m gateway.hub_server

Claude Desktop(App)

編輯 ~/Library/Application Support/Claude/claude_desktop_config.json,把 my-hub 加進 mcpServers,然後完全關閉再重開 Claude Desktop。

{
  "mcpServers": {
    "my-hub": {
      "command": "{{ py }}",
      "args": ["-m", "gateway.hub_server"],
      "env": { "PYTHONPATH": "{{ proj }}" }
    }
  }
}

Cursor

編輯 ~/.cursor/mcp.json(格式同上)。

{
  "mcpServers": {
    "my-hub": {
      "command": "{{ py }}",
      "args": ["-m", "gateway.hub_server"],
      "env": { "PYTHONPATH": "{{ proj }}" }
    }
  }
}

其他 MCP client(通用)

凡是支援 stdio MCP 的 client,填以下三項即可:

command : {{ py }}
args    : ["-m", "gateway.hub_server"]
env     : { "PYTHONPATH": "{{ proj }}" }
接上後,client 的工具清單會出現你 Hub 聚合的所有下游工具(如 orgpulse__…)。要移除:claude mcp remove my-hub,或從設定檔刪掉那段。

註:目前是 stdio(client 自行啟動 Hub)。若想改成「貼一個 URL 就連」的遠端 Hub,需另把 hub_server 跑成 HTTP 服務(未來項目)。
