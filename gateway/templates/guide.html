📖 上手指南

五分鐘搞懂這套 Hub 在做什麼、怎麼開始。

這是什麼

Claude 只連 一個 Hub;你要用的各種工具都掛在 Hub 後面,由 Hub 幫你合併、整理、記錄。

Claude ──► 🧩 MCP Hub ──┬──► 下游 MCP(別人寫的,如 orgpulse / git) ├──► 自訂工具(你把一支 HTTP API 包成工具) └──► 複合工具(把多步查詢包成「一個」工具)

好處:接一次(Hub),之後加減工具都在這個管理台,不用一直改 Claude 設定。

5 分鐘上手

  1. 啟動管理台
    在專案目錄執行 ./start.sh(或 python -m gateway.web),打開 http://localhost:8765。你現在就在這裡。
  2. 把 Hub 接進 Claude Code
    複製這行執行一次,之後重開 Claude Code 才會載入:
    claude mcp add my-hub -e PYTHONPATH="{{ proj }}" -- "{{ py }}" -m gateway.hub_server
  3. 加一台下游工具
    回 Servers →「+ 新增下游」貼上 MCP 設定 JSON(遠端 URL 或本機 stdio 皆可)。
  4. 回 Claude 直接問
    你加的下游工具會以 下游名__工具名 自動出現在 Claude,直接用自然語言叫用即可,呼叫記錄看 Logs。

名詞速查

下游別人寫好的 MCP server,你把它接進 Hub(遠端 http 或本機 stdio)。
自訂工具沒有現成 MCP 時,把一支 HTTP API 填一填就包成工具。
複合工具把「要跑好幾步」的查詢包成一個工具,Claude 叫一次就好。
Skill教 Claude「什麼情境該用哪個工具、怎麼呈現」的劇本;用複合工具頁的調適台產出。
需確認把危險工具標記後,Claude 呼叫前會先問你(對話內彈窗或核准頁)。
